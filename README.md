# Nosso Novo Lar — Ivan & Shay

Convite de casamento para 24/01/2027, com catálogo de presentes, contribuição via Pix e confirmação de presença preparada para envio pelo próprio convidado via WhatsApp.

## Publicação
O site é publicado pelo GitHub Actions em GitHub Pages: https://p63727330-del.github.io/Ivan-Shay/

## Desenvolvimento local
```bash
npm install
npm run dev
```

## Privacidade e pagamentos
- O site não grava confirmações de presença, escolhas de presentes nem comprovantes.
- A contribuição é feita diretamente pelo aplicativo bancário do convidado para a chave Pix exibida no site. O site não processa pagamentos.
- Antes de divulgar, teste o QR Code com o aplicativo do banco e confira cuidadosamente o nome do destinatário e o valor.
- Não armazene chaves, tokens ou outros segredos neste repositório público.
